# Test matrix

Full suite (213 tests) run against each server, Sunset 0.8.1 on Horizon Nightly ba6344a: Horizon, vanilla, Spigot and
Folia on 31 Oct 2026 04:24–07:36; Paper and Purpur again 11:55–13:25 after the harness fix below (they first ran 170
and 165). Totals: Horizon 204, vanilla 208, Spigot 204, Paper 209, Purpur 202, Folia 161.

## What fails where

- Paper, Purpur and Folia (fixed): the player was never dead. These servers kick a chat command over 256 characters
  (the chat box's limit), and Auto Steal's chest was one 1100-character setblock, so the player was kicked there; the
  harness read the state's `"player": null` as still in the game, never rejoined, and every later test failed with
  no player ("still on the death screen"). Auto Respawn works on Paper. The harness now refuses commands over 256
  characters and rejoins after a kick.
- No Fall's 1 health (Horizon, Spigot, Purpur, at times vanilla; fixed): not fall damage. The 12-block drop teleported
  the player into a hill of the server's world above the cleared arena, which cost 1 suffocation damage before the
  fall. The arena is now cleared to 16 blocks; all four No Fall modes lose 0 health on vanilla, Horizon and Paper.
  Flight, Glide, Scaffold and Offhand failing on Horizon or Purpur in this table are likely the same terrain; rerun.
- Speed Mine's Damage mode (fixed, a measurement): every timed break but the first carried the game's 5-tick wait
  between breaks, and the plain stone figure was the one without it. With all measured alike Damage beats plain
  mining on Horizon's server and Paper (stone 17->13, iron 13->11, diamond 11->9, obsidian 193->137).
- Aim Assist (fixed, harness): the wire probe's "send" lines in the probe file broke the frame reader.
- Folia: Folia disables `/item` and `/data` ("Unknown or incomplete command"), and the harness gives every item with
  `/item replace`, so each test that needs an item in a given slot (blocks to place, tools, food, totems, name tags)
  has nothing to use; the Paper-family kick above did the rest. Not Sunset's protocol: the same tests pass on Paper.
  Testing on Folia would need items given another way (`/give` fills the first empty slot).
- No Render (water) fails on Paper and vanilla only because the world's terrain changes the picture.
